Agent Helpers

Functions that save, run and delete CodeQL queries for the OpenCode agents. A query is written to codeql-query or codeql-query-js, executed against a database in codeql-dbs, and the CSV result is returned. The higher-level helpers build a Java or JavaScript query, run it on <project>-java or <project>-js, and remove the temporary query file.

CodeQL MCP Server

MCP server that gives the codeql-agent three CodeQL lookups: classes with an annotation, classes that call a method, and Maven module dependencies. Start it as a stdio server:

python codeql_mcp.py

Each tool call is timed. The duration is appended to codeql_tools_time, which opencode_exp.sh reads after a codeql-agent run. Pass the project name (the last path segment), not the filesystem path, as proj_name.

Metrics Writer

Appends one experiment row to a CSV file. opencode_exp.sh calls it after every run:

python3 append_metrics.py <csv_file> <value> [<value> ...]

Every argument after the file path becomes one cell of the new row. The header is written by the shell script, not by this file.

 1# Copyright (c) 2026 Ksenia Kotelnikova
 2# SPDX-License-Identifier: MIT
 3
 4"""
 5Append one row of experiment metrics to a CSV file.
 6
 7Called from opencode_exp.sh after each agent run:
 8
 9    python3 append_metrics.py <csv_file> <value> [<value> ...]
10
11Every argument after the file path becomes one cell of the new row.
12"""
13
14import csv
15import sys
16
17csv_file = sys.argv[1]
18values = sys.argv[2:]
19with open(csv_file, "a", newline="", encoding="utf-8") as f:
20    writer = csv.writer(f)
21    writer.writerow(values)

OpenCode Experiment

Runs one project through an OpenCode agent thirty times and records llama.cpp and agent metrics.

./opencode_exp.sh <project_path>

AGENT_NAME at the top of the script selects the agent (reading-agent or codeql-agent). For each repetition the script starts a local llama server, waits until http://127.0.0.1:8080/health answers, then runs opencode run on the given project. After the agent exits it reads http://127.0.0.1:8080/metrics and, for codeql-agent, the tool timings from codeql_tools_time. The agent report is taken from report.json when that file exists. The row is appended to opencode-exp/<project>-<agent>.csv. OpenCode sessions created during the run are deleted before the next repetition.

Experiment Launcher

Runs opencode_exp.sh once for every project in the list inside the script.

Set PROJECTS_DIR to the directory that contains the cloned projects, then launch:

./exp_launcher.sh

A project that is not a directory, or whose run exits with a non-zero status, is reported at the end. The launcher itself exits with status 0.

 1# Copyright (c) 2026 Ksenia Kotelnikova
 2# SPDX-License-Identifier: MIT
 3
 4set -u
 5
 6SCRIPT="./opencode_exp.sh"
 7PROJECTS_DIR=""
 8
 9PROJECTS=(
10    "spring-kafka-microservices"
11    "roshanadh-springboot-microservices"
12    "spring-rabbitmq-messaging-microservices"
13    "ecommerce-microservices"
14    "Microservices-example"
15    "sample-spring-kafka-microservices"
16    "distributed-systems-microservice"
17    "E-Commerce-app"
18    "spring-kafka-microservices-app"
19    "sample-spring-microservices-new"
20    "pandaind-springboot-microservices"
21    "kafka-microservices-with-saga"
22    "microservices-architecture-mongodb"
23    "ghifariyudha-spring-boot-microservices"
24    "SpringBootMicroservices"
25    "spring-microservices-blueprint"
26    "ecommerce-microservices"
27    "spring-petclinic-microservices"
28    "library-microservices"
29    "piggymetrics"
30    "spring-boot-microservices-series-v2"
31)
32
33TOTAL=${#PROJECTS[@]}
34FAILED_PROJECTS=()
35INDEX=0
36
37for PROJECT_NAME in "${PROJECTS[@]}"; do
38    INDEX=$((INDEX + 1))
39    PROJECT_PATH="$PROJECTS_DIR/$PROJECT_NAME"
40
41    echo "========================================"
42    echo "Experiment $INDEX/$TOTAL on $PROJECT_PATH"
43    echo "========================================"
44
45    if [[ ! -d "$PROJECT_PATH" ]]; then
46        echo "Error: dir not found: $PROJECT_PATH"
47        FAILED_PROJECTS+=("$PROJECT_NAME (not found)")
48        echo
49        continue
50    fi
51
52    "$SCRIPT" "$PROJECT_PATH"
53    EXIT_CODE=$?
54
55    echo
56    echo "Exp $INDEX ($PROJECT_NAME) return code: $EXIT_CODE"
57    echo
58
59    if [[ $EXIT_CODE -ne 0 ]]; then
60        FAILED_PROJECTS+=("$PROJECT_NAME (exit code $EXIT_CODE)")
61    fi
62done
63
64echo "========================================"
65echo "Exps finished: $((TOTAL - ${#FAILED_PROJECTS[@]}))/$TOTAL succeeded"
66if [[ ${#FAILED_PROJECTS[@]} -gt 0 ]]; then
67    echo "Errors detected in projects:"
68    for P in "${FAILED_PROJECTS[@]}"; do
69        echo "  - $P"
70    done
71fi
72echo "========================================"
73
74exit 0

OpenCode Agents

Agent definitions live in .opencode/agents/. Both agents analyse a Java (Spring) microservice project and write one JSON report, report.json, with two lists: services (name and description) and relationships (source, target, purpose, description, evidence). The report is the last action of the agent.

reading-agent

File .opencode/agents/reading-agent.md. CodeQL tools are denied. The agent discovers services from the root build file or the directory layout, then reads each module’s configuration, its @SpringBootApplication class, and the classes that take part in communication (controllers, clients, messaging, gateway routes).

codeql-agent

File .opencode/agents/codeql-agent.md. CodeQL tools are allowed and are the primary source of evidence. The agent calls get_java_dependencies once, then search_java_annotation and search_java_method_calls for communication-related annotations and methods. File reads are limited to the root build file and to service configuration (.yml, .yaml, .properties), including Spring Cloud Config files when a config server is present. The proj_name argument of every CodeQL tool is the last segment of the project path, not the path itself.
